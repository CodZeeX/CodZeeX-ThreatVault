# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability
The CodZeeX team takes security seriously. If you discover a vulnerability within ThreatVault itself:
1. Please **DO NOT** create a public GitHub issue.
2. Email security vulnerability reports directly to: `fredapacitan@gmail.com` with the subject `[SECURITY] CodZeeX ThreatVault Vulnerability`.
3. We will respond within 48 hours to confirm receipt and begin coordinated disclosure.
