# Contributing to CodZeeX ThreatVault

Thank you for your interest in contributing to **CodZeeX ThreatVault**!
This repository is dedicated to advancing the open-source cybersecurity community through structured threat intelligence, detection rules, and system hardening benchmarks.

## How to Contribute:
1. **Sigma Rules**: Ensure rules adhere to Sigma specification with valid `title`, `logsource`, `detection`, and MITRE ATT&CK tags.
2. **YARA Rules**: Test rules for performance and verify minimal false positives on clean system binaries.
3. **CVE Advisories**: Include CVE ID, CVSS score, detailed vendor information, and practical defensive mitigation steps.
4. **Codebase**: Ensure all Python code is formatted, type-hinted where applicable, and passes unit tests (`pytest tests/`).

Code of Conduct applies to all interactions within the CodZeeX organization.
